## 设计决策

- **`.sln` 与 `*.csproj` 不入仓**：这些是 Unity 打开工程时自动生成的（根目录下 40+ 个 `*.csproj` 与 `Roguelike.sln` 全部是生成物）。代价是克隆后需用 Unity 打开一次才有 sln —— 属标准做法。
- **`.com-unity-codely.json` 必须忽略**：它不是配置而是 Codely 桥接的**运行时状态**，含 `seq` 与 `last_heartbeat`，每次开编辑器都变。入库会导致每次提交都有无意义差异。
- **`.meta` 必须提交**：`.gitignore` 中未忽略任何 `*.meta`。丢了 `.meta` Unity 会重建 GUID，预制体与场景引用会全部断开。
- **提交身份为占位符**：工程内无任何作者线索（`ProjectSettings` 里是 `companyName: DefaultCompany`），故设仓库级 `Roguelike Dev <dev@localhost>`。**这不是用户的真实身份**，需用户确认后替换。
- **24MB 的 `Docs/Design/h5/assets/` 正常入仓**：它是策划案的交付物组成（HTML 靠它才能渲染）。本机虽装了 git-lfs，但该目录是「一次性生成、不常改」的派生资源，用 LFS 只会增加克隆门槛，故走普通提交。
