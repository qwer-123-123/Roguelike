## 关键步骤

1. 写 `PlayerController.cs`（表现层 MonoBehaviour）：读取 `Input.GetAxisRaw` 移动玩家（WASD / 方向键），对角移动归一化，`[SerializeField]` 暴露移速。
2. 写 `CameraFollow.cs`（表现层 MonoBehaviour）：`LateUpdate` 平滑跟随目标，offset z=-10 保持 2D 正交距离。
3. 通过 unity-skills REST 搭场景：
   - 创建 `Player`（Quad 占位视觉）+ `PlayerController` 组件。
   - `Main Camera` 设为正交（size=5）+ `CameraFollow` 组件。
   - `CameraFollow.target` 指向 Player（经 `component_set_serialized_property`，因裸反射 `component_set_property` 找不到 `[SerializeField] private` 字段）。
4. 保存场景为 `Assets/Scenes/Main.unity`。
