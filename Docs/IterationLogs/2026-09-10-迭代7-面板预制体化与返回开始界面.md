## 关键步骤

1. **`StartNewGameCommand` 支持目标阶段**：新增 `StartNewGameCommand(GamePhase targetPhase)` 重载，默认重载走 `Playing`；传 `Ready` 即「返回开始界面」。重置逻辑（数据归零 + `ReleaseAll` 清空场地 + 清活跃敌人表 + 复位管理器 + 隐藏升级面板）两条路径复用同一份。
2. **`StartMenuPanelController` 去代码建 UI**：删除 `CreateUI()`，改为 `[SerializeField] GameObject panel` + `Button startButton`，按钮在 `Start()` 里 `AddListener` 绑定。预制体 `Prefabs/StartMenuPanel.prefab`（Canvas + 面板 + 标题 + 按钮）。
3. **`GameOverPanelController` 去代码建 UI**：删除 `CreateUI()`/`MakeText()`，改为 4 个序列化引用（`panel` / `timeText` / `restartButton` / `mainMenuButton`）。预制体 `Prefabs/GameOverPanel.prefab`。
4. **新增「返回开始界面」按钮**：与「重开」并排放在死亡面板底部。点击 → `StartNewGameCommand(GamePhase.Ready)` → 清空场地并回到 `Ready`，开始界面重新出现。
5. 预制体实例直接放入 `Scenes/Main.unity`。

## 设计决策

- **预制体实例放场景内**（而非运行时加载）：MVP 阶段不引入 ResKit/Resources，与既有 Enemy/Projectile/ExpDrop 的做法一致。
- **返回开始界面时清空场地**：复用 `StartNewGameCommand` 的 `ReleaseAll()`，回到开始界面即干净状态，再开局不会残留上一局的怪。
- **按钮绑定写在代码里而非预制体的 onClick 持久化监听**：`Start()` 里 `AddListener`，避免手改预制体的 UnityEvent 序列化数据；代价是绑定关系不在 Inspector 里可见。
- **Canvas 层级**：开始界面 `sortingOrder = 100`，死亡面板 `90`，保证开始界面压在死亡面板之上。
