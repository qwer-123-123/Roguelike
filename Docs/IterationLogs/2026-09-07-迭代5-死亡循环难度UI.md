## 关键步骤

1. 扩展 `GameStateModel`：加 `Wave` / `Kills` / `SurvivedTime` / `IsGameOver`（`BindableProperty`）。
2. 新增 `GameOverCommand`：玩家死亡写 `IsGameOver=true`。
3. 新增 `DifficultySystem`：按存活时间推进波次 + 动态刷怪间隔。
4. 新增 `GameFlowController`（MonoBehaviour，IController）：驱动存活时间累加 → 驱动难度/波次。
5. 改造 `PlayerController`：加血量 + `TakeDamage` + 死亡发命令（保留 `AddMoveSpeed`）。
6. 改造 `EnemyController`：加 `touchDamage` + 距离检测接触伤害（带冷却，无需物理组件）+ 击杀数累加。
7. 改造 `EnemySpawner`：改用动态刷怪间隔（随时间缩短）+ 保留打怪循环。
8. 新增 `HudController`：程序化 HUD（血量/时间/波次/击杀）。
9. 新增 `GameOverPanelController`：死亡面板 + 重开按钮（角色用 `LoadScene` 重载当前场景实现）。
10. 在场景中创建 GameFlow / HUD / GameOver 三个对象，注册 `DifficultySystem`。

## 备注

- 接触伤害改用距离检测（`sqrMagnitude < 0.6²` + 冷却）而非物理碰撞，避免配置 2D 物理组件的复杂性。
- 重开通过 `SceneManager.LoadScene(当前场景)` 重载实现（简单可靠）。
- HUD 血量用 Update 轮询（玩家血量是运行时本地状态，不放 Model，符合 QFramework 原则）。
